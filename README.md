

# House Prices - Random Forest
Predicting house prices with a Random Forest Regressor (Kaggle House Prices competition).

Steps: explore data, handle nulls, one-hot encoding, train/validation split, train, evaluate, predict.

Validation RMSE (log): 0.146 | R2: 0.886

Data: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques
